1. Singleton Pattern

Được sử dụng tại file singleton.py cho lớp DatabaseConnection.

db1 = DatabaseConnection()
db2 = DatabaseConnection()
print(db1 is db2) # True (Thread-safe Lock)

Tránh Race Condition, đảm bảo toàn bộ hệ thống đọc/ghi trên cùng một tệp SQLite orders.db.

2. Factory Method

Được sử dụng tại factory.py. Trả về lớp con cụ thể của Order.

order = OrderFactory.create_order(product_id, order_type)
cost = order.get_shipping_cost() # Standard ($2.5) hoặc Express ($15.0)

Giúp mở rộng thêm các lớp vận chuyển khác (như Drone, Cargo) mà không sửa đổi cốt lõi Controller.

3. Facade Pattern

Được sử dụng tại facade.py. Cung cấp một giao diện đơn giản nhất cho luồng nghiệp vụ.

facade = OrderFacade()
result = facade.place_order(product_id, type, address)
# Ngầm gọi: Inventory.check() -> Payment.process() -> Shipping.arrange()

Tách biệt hoàn toàn tầng điều hướng (Controller) khỏi sự phức tạp của 3 subsystem nghiệp vụ độc lập.

4. State Pattern

Được sử dụng tại state.py để quản lý trạng thái của đơn hàng.

# PendingState -> (proceed) -> PaidState -> (proceed) -> ShippedState
context.proceed() # Chuyển trạng thái thông minh không dùng if/else

Tránh Spaghetti Code lồng if/else dài dòng khi cập nhật luồng nghiệp vụ đơn hàng.

5. Iterator Pattern

Được sử dụng tại iterator.py cho collection OrderCollection.

# Triển khai __iter__ và __next__ để duyệt qua orders
order_db = OrderCollection()
for o in order_db:
    print(o["details"])

Cho phép Controller duyệt qua danh sách các đơn hàng trả về mà không cần biết cấu trúc danh sách mảng nội bộ.
